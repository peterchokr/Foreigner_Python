```markdown
## 2️⃣ Writing to Text Files (텍스트 파일 쓰기)

When you create a file, you need to specify the mode. 
Write mode ("w") creates a new file or overwrites an existing file. 
This is the most common way to save data to a file.

파일을 생성할 때는 모드를 지정해야 합니다. 
쓰기 모드("w")는 새 파일을 만들거나 기존 파일을 덮어씁니다. 
이것이 데이터를 파일에 저장하는 가장 일반적인 방법입니다.

### Opening and Closing Files (파일 열기와 닫기)

To create a file, use the `open()` function with the write mode.

파일을 만들려면 쓰기 모드로 `open()` 함수를 사용합니다.

```python
# Open file (파일 열기)
file = open("test.txt", "w")  # w = write mode (쓰기 모드)
file.write("Hello!")
file.close()  # Must close! (반드시 닫아야 함!)
```
```

## 🔑 Quiz Answers and Explanations

**Answer 1: 2**

The `"w"` mode opens a file in write mode. 
If the file doesn't exist, it creates a new one; 
if it exists, it deletes the existing content.

`"w"` 모드는 파일을 쓰기 모드로 엽니다. 
파일이 없으면 새로 만들고, 있으면 기존 내용을 삭제합니다.
